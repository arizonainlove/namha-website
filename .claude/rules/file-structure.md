# Cấu Trúc File

```
namha-website/
├── index.html          # Trang chính (single page)
├── css/
│   ├── main.css        # Global styles, variables, reset, scroll animations
│   ├── components.css  # Cards, buttons, navbar, toggle
│   └── sections.css    # Per-section styles (10 sections)
├── js/
│   └── main.js         # Scroll reveal, navbar, smooth scroll, accordion, share
├── assets/
│   └── images/
│       ├── namha-portrait.webp
│       ├── logo.png
│       └── og-image.jpg    # 1200×630 cho social share
```
