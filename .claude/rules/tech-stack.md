# Tech Stack

| Hạng mục | Lựa chọn |
|----------|----------|
| Ngôn ngữ | HTML5, CSS3, JavaScript (ES6+) |
| Framework CSS | CSS thuần với custom properties |
| Animation | CSS Transition + IntersectionObserver |
| Icon | Heroicons hoặc Phosphor Icons (SVG inline) |
| Font | Google Fonts — `Be Vietnam Pro` (sans-serif) cho cả heading và body |
| Hosting | GitHub Pages / Netlify (static) |
| Không dùng | React, Vue, jQuery, Bootstrap, Tailwind, AOS CDN |
